# Runtime dependencies for sync.py
#
# PDF -> Markdown conversion (always required). Pinned exactly, for two
# reasons:
#
#   1. pymupdf4llm 2.0 is an EMPTY placeholder package. Upstream moved the
#      4llm code into pymupdf 2.x and published 2.0 as a stub to dodge a pip
#      upgrade bug, so `pip install pymupdf4llm` installs nothing importable
#      and the sync dies at `import pymupdf4llm`. Moving to pymupdf 2.x means
#      a code change here, not just a version bump.
#   2. Conversion output shifts between versions (heading levels, page
#      furniture). Since change detection diffs the generated Markdown, an
#      unpinned converter rewrites documents that UCI never touched.
#
# 1.28.2 is the last 1.x release and matches the most recently converted
# documents in docs/.
pymupdf4llm==1.28.2

# Documentation site build/deploy. Only invoked by `sync.py --docs` /
# `--ghdeploy`, which shell out to the `properdocs` CLI. properdocs ships no
# themes itself; the Read the Docs theme (set in docs/properdocs.yml) is a
# separate package. Capped below 2.0: a major release here would break the
# build the same way pymupdf4llm 2.0 broke the sync.
properdocs>=1.6.7,<2
properdocs-theme-readthedocs>=1.6.5,<2
